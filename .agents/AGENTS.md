# AGENTS.md

## Scope

This directory stores reusable skills and operational guidance for agents.

## Usage

- Keep skill guidance practical, short, and specific to this repository.
- Update the relevant skill when recurring patterns appear in session notes.
- Do not duplicate global policy here unless it helps local clarity.

## Subtree Index

- `skills/`: skill folders, one topic per folder, each with a `SKILL.md` and local `AGENTS.md`.
