# AGENTS.md

## Scope

This directory is the skill registry for agent workflows.

## Rules

- Use one folder per skill domain, in kebab-case.
- Keep `SKILL.md` focused on actionable bullets.
- Merge new learnings into existing skills instead of creating duplicates.

## Subtree Index

- `git/`: git safety and remote rules.
- `just/`: formatting, linting, test workflow via `Justfile`.
- `neovim-automation/`: editor automation and key handling patterns.
- `nix/`: flake/module conventions.
- `opencode-docs-index/`: OpenCode docs index maintenance.
- `session-management/`: session processing lifecycle.
- `tmux-e2e-cli-agent/`: tmux-driven CLI E2E patterns.
- `web-search/`: reproducible web search usage.
