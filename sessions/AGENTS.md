# AGENTS.md

## Scope

Session lifecycle workspace for active and historical task notes.

## Structure

- `sessions/*.md`: active or unprocessed notes.
- `sessions/archived/*.md`: processed historical notes.
- `sessions/raw/*.md`: raw transcript exports.

## Rules

- Maintain one actively updated session note per substantive task.
- Include scope, steps, decisions, bugs/fixes, and follow-ups.
- Before archiving, extract durable learnings into relevant skill files.

## Subtree Index

- `archived/`: processed notes.
- `raw/`: raw exports.
